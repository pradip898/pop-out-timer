### A Tiny Elegant Handy Timer for Personal Work

A Pomodoro timer and a stopwatch that you can pop out into a small always-on-top window, so it stays visible while you work in other apps, and pause or start it without switching back.

URL=

Open `index.html` in a browser. There is nothing to install, and nothing is saved.

#### Functions

- **Pomodoro:** focus, short break and long break (a long break after every 4th focus session). Durations are adjustable in Settings.
- **Stopwatch:** start, pause, reset and lap.
- **Pop-out window:** the ⧉ button (or `P`) opens the timer in a small window with Start/Pause, mode switching and the time. Close it to pop back.
- **Keyboard:** `Space` start/pause, `R` reset (page only), `L` lap, `P` pop out.

#### Browser support

The always-on-top pop-out needs Chrome or Edge. In other browsers it opens as a regular small window instead.
